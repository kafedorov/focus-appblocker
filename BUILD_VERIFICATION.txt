Removed Back button from overlay. Added explicit session-start confirmation for
VK, Telegram, YouTube and LANGAME. Inspection and preview never start a timer;
the only start call is in the confirmation handler, after fresh foreground/rule
checks. Group and calendar-slot mismatch reject stale confirmation.
Active sessions continue without another prompt. Messaging outside schedule is
unrestricted. Existing hourly/weekly preference keys are retained for upgrades.

YouTube has one continuous 30-minute local-calendar-day session shared by the
official app and identified website. Midnight cuts a late session short; reboot
consumes a started day. Shorts/domain/manual/full-app denials precede the offer.

accessibility descriptions and constrained footer fallback. Document subtrees
and tab previews are excluded. Tests use synthetic UI element descriptions,
including the screenshot host shape; they are not tests on installed Yandex.
Known YouTube origin can survive recognized fullscreen with hidden toolbar;
the old path is discarded, so strict hidden-path Shorts policy is preserved.

also handles focus being taken by the accessibility overlay.

must be checked on device. An inaccessible browser origin can bypass web rules;
