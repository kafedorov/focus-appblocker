# FocusGuard

Нативное Android-приложение «Фокус». Интерфейс на Java, package `ru.focusguard`, minSdk 26, compile/target SDK 36. Правила и ограничения описаны в README.md и docs/.

## Работа с проектом

- По умолчанию редактируй исходники непосредственно в этом репозитории. Не переноси разработку в отдельную временную копию с последующим копированием файлов обратно. Рабочее дерево создавай, когда оно действительно необходимо или пользователь этого просит.
- Пользователь не хочет отдельные `.diff` или `.patch` файлы с отчётом об изменениях. Используй обычный Git diff и панель изменений приложения.
- После функциональных правок оставляй изменения незакоммиченными для просмотра, если пользователь не попросил сохранить коммит. Первоначальный коммит фиксирует состояние версии 0.1.5.
- APK, кэши, локальные пути, переменные окружения и ключи подписи не добавляются в историю Git.

## Сборка и проверка

- Используй JDK 17, Android SDK 36, Build Tools 35.0.0, Gradle Wrapper из проекта. `build.ps1` выполняет assembleDebug, lintDebug и coreCheck; локальный игнорируемый `local-env.ps1` содержит пути установленного инструментария.
- Сохраняй applicationId и существующий сертификат подписи, чтобы APK устанавливался поверх прежней версии с сохранением настроек. Не создавай новый ключ для обычного обновления.
- При изменении приложения повышай versionCode и versionName. Изменения только в Git-настройках и документации не требуют нового APK.
- Проверки coreCheck не заменяют испытания AccessibilityService на телефоне. Не утверждай, что проверил Samsung или Яндекс Браузер, если фактической проверки не было.

## Важное поведение

- Начало нового ограниченного сеанса требует явного подтверждения; чтение состояния и показ окна не должны расходовать время.
- Лимит YouTube общий для официального приложения и распознанного сайта; разрешённый сеанс не отменяет запрет Shorts и ручные блокировки.
- Сохраняй существующие ключи настроек, состояния сеансов и код восстановления при обновлениях. У экранной защиты всегда должен оставаться путь восстановления через сам Фокус.
