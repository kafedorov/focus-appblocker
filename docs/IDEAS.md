# Следующие полезные функции

## Приоритетные

1. **Интеграция с твоим VPN-клиентом.** Узнать используемые клиенты и протоколы, проверить, позволяют ли они задать DNS и правила доменов. Фильтр в том же сетевом клиенте закрывает пробелы, которые нельзя устранить второй VPN-службой Android.
2. **Профили «работа», «вечер», «сон».** Расписание по дням недели, отдельные лимиты выходных, несколько временных интервалов.
3. **Сеансы по выбору.** Переключение между непрерывным окном и фактическими минутами на экране, кнопка осознанного начала сеанса, предупреждение за минуту до конца.
4. **Отложенное ослабление каждого правила.** Ужесточение применяется сразу, смягчение — завтра; сейчас реализована общая фиксация настроек.
5. **Доверенный человек.** Код хранит другой человек; временное разрешение для конкретного приложения с причиной и сроком. Не превращать доступ к важной связи в необратимую блокировку.
6. **Офлайн-статистика.** Количество попыток открыть заблокированное приложение и время по группам — без содержимого сообщений и истории URL.
7. **Обновления базы доменов.** Проверка источника и контрольной суммы, дата обновления, откат при ошибочной базе. Сейчас в APK статический снимок.
8. **Защищённый управляемый браузер.** Собственный браузер с точной проверкой навигации для тех случаев, где адресная строка стороннего браузера недоступна. Потребует отдельно ограничить обход через другие браузеры.

## Как добавить ИИ для определения игр

В этой версии ИИ-запросов нет. Android-категория быстрая и локальная, а карантин ловит неизвестное приложение независимо от качества классификации.

Возможная схема:

1. При установке сохранить только package name, название, категорию и доступное описание из доверенного каталога. Описание не появляется автоматически из Android PackageManager: нужен источник метаданных.
2. Если категория не определена, оставить приложение в карантине.
3. Отправить метаданные своему серверу для классификации `game / not_game / unknown` с оценкой уверенности и короткой причиной. Одно название не является надёжным основанием; описания могут вводить классификатор в заблуждение.
4. Держать ключ API на сервере. Не встраивать личный секрет в APK: его можно извлечь.
5. Кэшировать решение по пакету и версии. При недоступности сети оставлять карантин и возможность ручного решения, не считать молчание сервера разрешением.

Это потребует отдельной настройки сервера, источника метаданных и платного API при выбранной модели. Никакие сообщения или содержимое экрана для такой проверки не нужны.

## Чего не обещать

- Определение всех игр по названию со 100% точностью.
- Универсальное удаление Shorts из всех версий YouTube и браузеров.
- Одновременную работу двух независимых VPN Android в одном профиле.
- Абсолютную невозможность удаления или обхода на личном устройстве.
