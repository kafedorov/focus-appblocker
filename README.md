# Фокус — Android-приложение для личных ограничений

Версия 0.1.5. Изменения описаны в `CHANGELOG.md`. Устанавливай новый APK поверх предыдущих версий, не удаляя старое приложение: настройки и код восстановления сохранятся.

Приложение для Samsung Galaxy A54 5G / Android 16. Нативный интерфейс Android на Java, устанавливаемый APK. Минимальная версия Android — 8.0; целевая — Android 16.

## Что реализовано

- **ВК и Telegram:** отдельный непрерывный сеанс для каждого мессенджера, по умолчанию 10 минут в каждом календарном часу с 07:00 до 19:00. Перед новым сеансом появляется подтверждение; только «Начать сеанс» запускает таймер. Выход его не останавливает. С 19:00 до 07:00 ограничений нет. Настраиваются начало, конец и длительность. Подтверждение требуется перед каждым новым часовым сеансом; активный сеанс продолжается без повторного вопроса. У границы часа или конца расписания доступное окно будет короче 10 минут. Сеансы переживают перезапуск процесса; перезагрузка не восстанавливает уже использованный сеанс текущего часа.
- **LANGAME:** один непрерывный сеанс на 10 минут за неделю, только в субботу по времени телефона. В остальные дни доступ запрещён. Перед новым сеансом появляется подтверждение; только «Начать сеанс» запускает таймер. Выход его не останавливает. Сеанс заканчивается через 10 минут или при наступлении воскресенья, что раньше. Перезагрузка завершает начатый сеанс текущей недели. Неиспользованное время не переносится. Ограничение включено по умолчанию и независимо от расписания мессенджеров; отключается в «Правилах», если настройки не зафиксированы.
- **YouTube: 30 минут в день.** Один непрерывный сеанс после подтверждения, общий для официального приложения и сайта в поддерживаемых браузерах. Выход не приостанавливает таймер. Следующий день начинается в полночь по времени телефона; поздний сеанс ограничен полуночью. Перезапуск процесса не сбрасывает его, после перезагрузки начатый сеанс текущего дня считается использованным. Ограничение включено по умолчанию, отключается в «Правилах» до фиксации. Полный запрет YouTube и Shorts сильнее разрешённого сеанса.
- **YouTube Shorts:** определение экрана Shorts в официальном приложении YouTube, пути `/shorts` и доступных признаков проигрывателя в браузере. Дополнительный строгий режим закрывает YouTube, если браузер показывает домен без пути страницы: в таком случае могут блокироваться также обычные видео и главная. Режим включён по умолчанию, отключается в «Правилах». Отдельно можно блокировать YouTube целиком.
- **Домены:** пользовательские маски `*` и `?`, точные домены и IDN. Проверяются в адресной строке поддерживаемого браузера и в запросах локального DNS-фильтра.
- **Взрослые сайты:** локальный снимок HaGeZi NSFW, 90 159 доменов, версия `2026.1026.0958.06`. Совпадение включает поддомены. В браузере работает при стороннем VPN; DNS-фильтр использует ту же базу и дополнительно Cloudflare for Families.
- **Игры:** проверка категории Android `CATEGORY_GAME` и старого `FLAG_IS_GAME`; при отсутствии категории игра может быть пропущена. Неизвестные приложения можно блокировать карантином.
- **Новые приложения:** карантин всех новых несистемных приложений, которых не было при первом запуске Фокуса. Ручные исключения и блокировка любого выбранного приложения. Системные приложения в карантин не попадают; телефон, клавиатура, главный экран и настройки исключены из всех блокировок.
- **Защита правил:** код восстановления; фиксация настроек; запрос снятия фиксации через 24 часа. Отсчёт монотонный, перевод часов его не ускоряет. После перезагрузки ожидание начинается заново, время выключенного телефона не засчитывается.
- **Экранная защита удаления:** отдельный переключатель, по умолчанию выключен. Работает при зафиксированных правилах и включённой службе. Перекрывает подтверждение удаления и собственную страницу Фокуса «О приложении» с доступной кнопкой удаления, чтобы сработать раньше подтверждения. Для изменения разрешений сначала сними фиксацию в Фокусе. Настройки и удаление других приложений доступны. Подробности — `docs/UNINSTALL_PROTECTION.md`.

## VPN: что продолжает работать

| Функция | При стороннем VPN |
|---|---|
| Расписание ВК и Telegram | Да, при включённой службе Фокуса |
| Дневной сеанс YouTube | Да, при включённой службе Фокуса |
| Недельный сеанс LANGAME | Да, при включённой службе Фокуса |
| Блокировка игр / карантин | Да, при включённой службе Фокуса |
| Shorts в YouTube | Да, если экран распознаётся |
| Маски и локальная база в браузере | Да, если адрес страницы доступен службе |
| Локальный DNS-фильтр | Нет: Android допускает один активный VPN на пользователя |
| Фильтрация доменов во всех сторонних приложениях через другой VPN | Не реализована |

Локальный DNS-фильтр не является транспортным VPN: он перехватывает только DNS на синтетический адрес. Он не скрывает IP и не заменяет VPN для доступа к сети. Перед его включением приложение всегда предупреждает о замене другого VPN. При отзыве разрешения запоминается, что DNS-защита отключена. После перезагрузки приложение не запускает её поверх обнаруженного активного VPN.

Для строгой сетевой фильтрации **вместе** с выбранным сторонним VPN нужна поддержка DNS/блоклистов в самом VPN-клиенте либо согласованный с ним внешний DNS. Android Private DNS может работать вместе с некоторыми VPN, но это нужно проверить для конкретного клиента. Фокус не гарантирует такую совместимость и не меняет настройки сторонних VPN.

## Установка и первый запуск

1. Передай `apk/FocusGuard-0.1.5-debug.apk` на телефон и установи поверх прежней версии. Это тестовая сборка, не публикация в Google Play.
2. Открой Фокус. Пока не фиксируй настройки. При обновлении приложение автоматически пытается снять прежние системные ограничения; если это не удалось, на «Обзоре» появится сообщение.
3. На вкладке «Обзор» нажми «Включить проверку открытых приложений», прочитай описание доступа и включи службу в специальных возможностях Android.
4. Если Android запрещает включение службы после установки APK: открой карточку приложения, меню дополнительных действий и разреши ограниченные настройки. Путь зависит от One UI и источника установки. Не меняй другие системные ограничения без необходимости.
5. Для Фокуса выбери расход батареи «Без ограничений» и добавь его в список никогда не спящих приложений Samsung, если этот пункт доступен.
6. Пока пользуешься другим VPN, **не включай DNS-фильтр**. Служба экрана и локальная база продолжат работу в поддерживаемом браузере.
7. Для отдельного теста DNS-фильтра отключи другой VPN, частный DNS Android и защищённый DNS браузера. Затем запусти DNS-фильтр в Фокусе и подтверди системный запрос. Не включай системный режим «Блокировать подключения без VPN»: обычный трафик намеренно не проходит через DNS-туннель, и такой режим нарушит подключение.
8. Проверь все блокировки, затем создай и надёжно сохрани код восстановления. По желанию зафиксируй настройки.
9. Чтобы включить экранную защиту удаления, включи «Перекрывать попытки удаления при фиксации», затем зафиксируй правила. Должна работать проверка открытых приложений. Кнопка «Открыть Фокус» на экране блокировки оставляет доступ к восстановлению. Проверь работу на своей версии One UI: по скриншоту невозможно подтвердить, какие элементы доступны службе.

Служба экрана читает активный пакет, адрес браузера и элементы YouTube. Она не записывает сообщения, историю посещений, скриншоты или содержимое экранов. Для продолжения ограничения при распознанном полноэкранном просмотре последний адрес браузера временно хранится только в памяти процесса. DNS-запросы в режиме фильтра отправляются Cloudflare по UDP/53 без дополнительного шифрования. Других внешних сервисов и аналитики нет.

## Поддерживаемые приложения и браузеры

- ВК: `com.vkontakte.android`, VK Мессенджер: `com.vk.im` — общая группа «ВК».
- Telegram: `org.telegram.messenger`, `org.telegram.messenger.web`, Telegram X: `org.thunderdog.challegram` — общая группа «Telegram».
- LANGAME: `com.f5computers.langame_aggregator`, «LANGAME. Компьютерные клубы». Сверено со страницей приложения: https://play.google.com/store/apps/details?id=com.f5computers.langame_aggregator. Другие приложения сети и веб-сайты не включены в этот недельный лимит.
- Веб-версии: `web.telegram.org`, `vk.com`, `vk.ru` и поддомены ВК используют сеанс соответствующей группы, если адрес доступен.
- Обработчики определения адреса: Chrome, Samsung Internet, Firefox, Firefox Focus, Edge, Brave, Yandex, Opera. Упоминание в списке означает наличие обработчика, **а не подтверждённый тест каждой версии браузера**.
- Для Яндекс Браузера добавлены обработка нижней панели адреса, дополнительные варианты идентификаторов, описание элемента и осторожный поиск нативного текста у нижнего края. Документ страницы и список вкладок исключаются из поиска адреса. Результат на конкретной версии Яндекса ещё нужно проверить; скриншот не содержит дерево специальных возможностей.
- Альтернативные клиенты мессенджеров автоматически не относятся к группе; их можно блокировать вручную или карантином.

## Ограничения

- Защита игр закрывает установленное приложение при открытии, загрузку из магазина она не запрещает. Игра без категории может быть пропущена; карантин новых приложений закрывает этот пробел.
- LANGAME с недельным правилом не блокируется автоматическим карантином и категорией игры. Ручное «Всегда блокировать» запрещает сеанс полностью; «Всегда разрешать» не отменяет недельный лимит. Переустановка LANGAME не сбрасывает сеанс, очистка данных Фокуса может сбросить.
- Экранная защита зависит от доступности службы, системных событий, языка и структуры окон. Полностью исключить быстрое нажатие до события нельзя. Отключение службы, безопасный режим, отладка и сброс устройства остаются путями обхода.

- Окно подтверждения перекрывает интерфейс, но не приостанавливает сам сторонний процесс и не гарантирует остановку фонового звука. Это ограничение взаимодействия с экраном.
- Сборка и автоматические проверки не заменяют проверку на A54. Распознавание Shorts и адресной строки ещё нужно проверить на конкретных версиях YouTube, браузера и One UI.
- Обновление YouTube может поменять структуру экрана. Shorts на домашней странице как миниатюры не удаляются; блокируется распознанный проигрыватель/вкладка. Это не модификация YouTube.
- Скрытая или недоступная адресная строка, встроенный браузер мессенджера, изменённый клиент, прямой IP, свой DNS, DoH и DoT могут обходить часть доменных ограничений. Проверка экрана реагирует после открытия: это не фильтр HTTPS-запросов и не гарантия предотвращения первой загрузки страницы.
- Если виден домен YouTube, но скрыт путь, Фокус по умолчанию закрывает страницу в строгом режиме; если недоступен даже домен, этот способ не поможет. Точно отличить обычное видео от Shorts только по одному домену нельзя.
- DNS-фильтр обрабатывает IPv4/UDP DNS через свой адрес и ответы до 1400 байт. DNS-over-TCP в виртуальном интерфейсе и крупные/усечённые ответы пока не поддерживаются: возвращается ошибка DNS, возможна недоступность отдельных обычных сайтов. IPv6 обычного трафика пропускается вне туннеля; DNS-запросы AAAA обрабатываются как обычные DNS-запросы через IPv4.
- Ранее закэшированные ответы, открытые соединения и загруженные страницы DNS-фильтр не закрывает.
- Локальный список сайтов — снимок, без автоматического обновления. Возможны ложные срабатывания и пропуски. Редактируемые маски — отдельные правила, не редактор всего списка.
- Встроенного ИИ-классификатора нет. Обнаружение игры не делается по одному лишь названию с гарантией точности.

## Маска для имени сайта с любым окончанием

Впиши две строки, заменив `myname` своим именем:

```text
myname.*
*.myname.*
```

Первая блокирует `myname.ru`, `myname.com`, `myname.xyz`, `myname.co.uk`. Вторая добавляет `www.myname.ru`, `a.b.myname.com` и другие поддомены. Одна строка `*.myname.*` не включает корневой домен `myname.ru`: перед именем нужна часть с точкой.

Если нужно искать именно фрагмент в любом месте имени, используй `*myname*`. Эта маска шире: она также совпадёт с `notmyname.com`. Маски вводятся без обратных слешей, `https://` и пути страницы.

## Сборка проекта

Нужны JDK 17, Android SDK Platform 36, Build Tools 35.0.0, Gradle 8.13. AGP закреплён на 8.13.2. Gradle Wrapper включён в проект.

В Android Studio открой корень проекта, установи SDK 36 и собери вариант `debug`.

В PowerShell:

```powershell
./build.ps1 -JavaHome 'C:\path\to\jdk17' -SdkRoot 'C:\path\to\Android\Sdk'
```

Скрипт выполнит `assembleDebug`, `lintDebug` и `coreCheck`, затем положит APK в `apk/`. Можно передать параметры через `JAVA_HOME` и `ANDROID_SDK_ROOT`. На исходном компьютере также создан локальный файл окружения, который не включён в переносимый архив проекта.

Проверки отдельно:

```powershell
./gradlew.bat :app:coreCheck :app:lintDebug
```

Исходники:

- `app/src/main/java/ru/focusguard/core` — маски, список доменов, расписание и DNS-пакеты, без зависимости от Android.
- `GuardAccessibilityService.java` — анализ активного приложения, адреса и Shorts, экран блокировки.
- `DnsVpnService.java` — дополнительный локальный DNS-фильтр.
- `docs/UNINSTALL_PROTECTION.md` — включение, восстановление и ограничения экранной защиты удаления.
- `MainActivity.java` — русский интерфейс и настройка правил.
- `docs/SESSIONS.md` — подтверждение, дневной YouTube и календарные границы.
- `docs/TESTING.md` — сценарии проверки на телефоне и результаты сборки.
- `docs/IDEAS.md` — варианты развития, включая ИИ-классификацию.
- `THIRD_PARTY.md` — источник, версия и лицензия базы взрослых сайтов.
